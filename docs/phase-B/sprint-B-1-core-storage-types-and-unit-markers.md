# Sprint B-1: Core Storage Types And Unit Markers

## Goal

Implement the primary quantity container and the first unit marker types.

## Status

`Not Started`

## Deliverables

1. Core `Quantity<Unit, Storage>` or equivalent
2. Foundational unit marker traits
3. Initial dimensions for distance, time, temperature, velocity, and acceleration
4. Size assertions demonstrating zero additional storage overhead

## Dependencies

- Sprint A-3

## Unblocks

- Sprints B-2, B-3, B-4

## Exit Criteria

1. Scalar quantities are zero-overhead over their storage payload.
2. Unit marker casing rules are enforceable in code.
